# OpenCart Demo Manual Testing Project

## Project Overview

This project contains manual test cases and bug reports for the OpenCart demo e-commerce application.

The goal of this project is to practice manual software testing by testing common e-commerce user flows such as registration, login, product search, cart functionality, checkout flow, and form validation.

## Application Under Test

**Application:** OpenCart Demo  
**URL:** https://demo.opencart.com/

## Tested Modules

- User registration
- Login and logout
- Product search
- Product details page
- Add to cart functionality
- Shopping cart
- Checkout flow
- Form validation

## Testing Types Performed

- Functional testing
- UI testing
- Positive testing
- Negative testing
- Form validation testing
